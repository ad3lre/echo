## XSS findings

### Chat markdown pipeline — **Medium (mitigated)**

- **Where:** [`frontend/src/features/chat/viewModel/messageBodyMarkdown.ts`](../../frontend/src/features/chat/viewModel/messageBodyMarkdown.ts)
- **Mechanism:** marked → DOMPurify (allowlist) → Twemoji → DOMPurify again
- **Risk:** Wide allowlist (`style` attr, SVG/KaTeX tags) is a traditional bypass surface
- **Mitigation:** Double sanitization; SPA CSP `script-src 'self'`; automated XSS corpus passes ([`messageBodyMarkdown.xss.test.ts`](../../frontend/src/features/chat/viewModel/messageBodyMarkdown.xss.test.ts))
- **Status:** No script execution confirmed in tests; no prod exploit attempted (guests disabled)

### Profile fields (username, displayName, bio, customStatus) — **Low**

- **Validation:** Username regex in [`shared/usernamePolicy.ts`](../../shared/usernamePolicy.ts); displayName control-char checks in [`backend/src/auth/accountPolicy.ts`](../../backend/src/auth/accountPolicy.ts)
- **Render:** Vue `{{ }}` text interpolation (not `v-html`) in profile components
- **Status:** Safe by construction; HTML payloads render as literal text

### Server-rendered HTML (invites, email) — **Low**

- **Where:** [`backend/src/services/echoInviteSharePage.ts`](../../backend/src/services/echoInviteSharePage.ts)
- **Mechanism:** `escapeHtmlAttributeValue()` on all dynamic OG/body strings
- **Tests:** [`backend/src/tests/echoInviteSharePage.xss.test.ts`](../../backend/src/tests/echoInviteSharePage.xss.test.ts)

### Upload-served content XSS — **High (fixed this audit)**

- **Where:** [`backend/src/api/routes/echo/echoUploads.ts`](../../backend/src/api/routes/echo/echoUploads.ts), [`backend/src/services/echoUploadServe.ts`](../../backend/src/services/echoUploadServe.ts)
- **Issue:** DB-stored `content_type` could override extension guess; `image/svg+xml` allowed via `image/*`; no `nosniff` on API file responses (#82)
- **Fix:** Shared policy [`echoUploadContentTypePolicy.ts`](../../backend/src/services/echoUploadContentTypePolicy.ts); serve-time re-sanitize; block SVG/HTML/JS MIME types; `X-Content-Type-Options: nosniff`; `Content-Disposition: attachment` when coerced

### Paper editor KaTeX — **Medium (accepted scope)**

- **Where:** [`frontend/src/features/paper/editor/paperMarkdownMathDecorations.ts`](../../frontend/src/features/paper/editor/paperMarkdownMathDecorations.ts)
- **Note:** KaTeX `innerHTML` without DOMPurify; scoped to Paper collab feature, not public chat

## CSRF findings

### Global enforcement — **Working**

- **Where:** [`backend/src/auth/csrf.ts`](../../backend/src/auth/csrf.ts), hook in [`backend/src/bootstrap/httpPlugins.ts`](../../backend/src/bootstrap/httpPlugins.ts)
- **Mechanism:** Double-submit cookie + header; session-bound `csrfSecret` when `echo_sid` present
- **Tests:** [`backend/src/tests/csrf.enforcement.test.ts`](../../backend/src/tests/csrf.enforcement.test.ts), [`csrf.exemptPaths.test.ts`](../../backend/src/tests/csrf.exemptPaths.test.ts)

### Historical guest-upgrade bypass (#1) — **Fixed (verified)**

- `/api/v1/auth/guest/upgrade` is **not** CSRF-exempt (exact-path set only)
- Integration test confirms upgrade without CSRF → **403**

### Intentional exemptions — **Documented**

- Bootstrap routes (login, register, guest mint, refresh, OAuth starts) and webhook prefixes
- Matrix updated: [`docs/security/MUTATING_ROUTE_MATRIX.md`](../../docs/security/MUTATING_ROUTE_MATRIX.md) includes `echo-channel-webhooks` prefix

### Login CSRF — **Low (industry tradeoff)**

- Login/register remain CSRF-exempt by design for pre-session bootstrap

## Authorization / IDOR (adjacent)

### Bot install IDOR (#71) — **High (fixed this audit)**

- **Where:** [`backend/src/api/routes/echo/echoBotApplications.ts`](../../backend/src/api/routes/echo/echoBotApplications.ts)
- **Issue:** Any guild manager could install any bot by ID without ownership check
- **Fix:** Require `owner_user_id === authenticated user` before install
- **Test:** Static assertion in [`echoInviteSharePage.xss.test.ts`](../../backend/src/tests/echoInviteSharePage.xss.test.ts)

## Recommendations (implemented 2026-05-31 follow-up)

1. **DOMPurify hardening** — `ALLOW_UNKNOWN_PROTOCOLS: false` on chat markdown sanitize opts
2. **Profile text server-side strip** — `stripProfileHtmlMarkup` / `sanitizeProfileBio` / `sanitizeProfileCustomStatus` in [`accountPolicy.ts`](../../backend/src/auth/accountPolicy.ts); applied in auth stores
3. **`test:auth`** — switched to `node --import tsx` for ESM compatibility
4. **Paper KaTeX** — DOMPurify sanitize on `renderPaperKatexHtml` output
5. **Emoji autocomplete** — custom emoji `imageUrl` gated through `safeCustomEmojiUrl`
6. **Link unfurl** — outbound fetch restricted to `https:` only (#27)
7. **Turnstile** — `remoteip` included in siteverify when caller IP is known (#40)
