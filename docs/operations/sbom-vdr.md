# SBOM and VDR (OSV)

Echo publishes a **Software Bill of Materials** (SBOM) and a **Vulnerability
Disclosure Report** (VDR) for every tree that passes the push / release gates.

| Artifact | Path                                                               | Spec                   |
| -------- | ------------------------------------------------------------------ | ---------------------- |
| SBOM     | [`security/sbom/echo.cdx.json`](../../security/sbom/echo.cdx.json) | CycloneDX 1.5          |
| VDR      | [`security/sbom/echo.vdr.json`](../../security/sbom/echo.vdr.json) | Echo JSON (OSV-backed) |

Both are regenerated by **`bun run check:osv`**, which also fails the build when
Google [OSV](https://osv.dev) reports a non-allowlisted advisory against
`bun.lock` or `clients/apple/Package.resolved`.

## Why both

- **SBOM** — inventory of what we ship (npm + SwiftPM pins). Transparency for
  self-hosters, customers, and auditors.
- **VDR** — status of known vulnerabilities for that inventory (clean vs
  known_affected / accepted_risk). Complements the SBOM; when clean, `status` is
  `"clean"` and `vulnerabilities` is empty.

The CycloneDX file may also carry a `vulnerabilities` array when findings exist
(SBOM + embedded disclosure in one document).

## Pipeline wiring

| Gate                                         | Where                                                  |
| -------------------------------------------- | ------------------------------------------------------ |
| `bun run check:osv`                          | `test:ci:guards` → `ci:precheck` (local pre-push)      |
| `bun run check:dep-audit`                    | Same path; npm/`bun audit` high+ (unchanged)           |
| GitHub `security-audit`                      | Runs `check:dep-audit` + `check:osv`; uploads SBOM/VDR |
| GitLab `security-dep-audit` / `security-osv` | Same checks on MR + default branch                     |
| `publish:public-release`                     | Runs `check:osv` before appending to `release/1.0.0`   |

Default OSV fail level is **`all`** (any known advisory blocks). Override locally
with `ECHO_OSV_LEVEL=high` only for experiments; CI should keep `all`.

Emergency local bypass: `ECHO_SKIP_OSV=1` (ignored when `CI=true`).

## Allowlist

Temporary exceptions: [`server/ops/scripts/osv-allowlist.json`](../../server/ops/scripts/osv-allowlist.json).
Each entry needs `reason` + `expires` (`YYYY-MM-DD`). Prefer fixing via root
`overrides` + `bun install`.

## Tooling

- Scanner: Google **osv-scanner** pinned in
  [`ensure-osv-scanner.mjs`](../../server/ops/scripts/ensure-osv-scanner.mjs)
  (downloaded under `server/ops/.cache/`, gitignored).
- SBOM builder: [`generate-echo-sbom.mjs`](../../server/ops/scripts/generate-echo-sbom.mjs)
  (parses `bun.lock` + Apple `Package.resolved`).

```bash
bun run sbom:generate   # inventory only
bun run check:osv       # inventory + VDR + OSV gate
```
