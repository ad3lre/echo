# Atribuições

Este projeto usa recursos e bibliotecas das fontes a seguir. Respeite os termos de licença de cada uma.

---

## Twemoji (Gráficos de Emoji)

Os gráficos de emoji são fornecidos pelo **Twemoji**, © Twitter, Inc. e outros colaboradores.

- **Licença:** [Creative Commons Atribuição 4.0 Internacional (CC-BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- **Fonte:** [github.com/twitter/twemoji](https://github.com/twitter/twemoji) (Twemoji do Twitter/X)
- **Uso:** O seletor de emojis e a exibição de mensagens renderizam emojis usando arquivos SVG do Twemoji, por meio do pacote twemoji.
- **Recursos:** Arquivos SVG de [@twemoji/svg](https://www.npmjs.com/package/@twemoji/svg) (Twemoji 15), copiados localmente para evitar requisições a CDN.

**Requisito de atribuição:** Você deve dar o crédito apropriado, fornecer um link para a licença e indicar se foram feitas alterações. Nenhuma modificação foi feita nos gráficos de emoji.

---

## Dados de Emoji Unicode (unicode-emoji-json)

Os metadados de emoji e a organização por categorias são do **unicode-emoji-json**, de Mu-An Chiou.

- **Licença:** [MIT](https://github.com/muan/unicode-emoji-json/blob/main/LICENSE)
- **Fonte:** [github.com/muan/unicode-emoji-json](https://github.com/muan/unicode-emoji-json)
- **Uso:** Lista completa de emojis com categorias Unicode para o seletor de emojis.

## Ícones de Interface (Flaticon)

Os ícones de interface (busca, configurações, microfone, fones de ouvido, hashtag, mais, lista, emotes, GIF, controles deslizantes, avatares de usuário etc.) são do **Flaticon**.

- **Designer:** [SeyfDesigner](https://www.flaticon.com/authors/seyfdesigner) (Seyf Eddine)
- **Fonte:** [www.flaticon.com](https://www.flaticon.com)
- **Uso:** Ícones usados em todo o aplicativo para navegação, controles e elementos de interface.

**Requisito de atribuição:** Ícones feitos por [SeyfDesigner](https://www.flaticon.com/authors/seyfdesigner) do [Flaticon](https://www.flaticon.com).
